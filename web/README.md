# web/

Contiene EXCLUSIVAMENTE la landing page de WordHive.

## Tecnologias
- HTML5 semantico
- CSS Vanilla (custom properties, grid, flexbox, animaciones)
- JavaScript ES Modules (sin frameworks)
- Google Fonts: Outfit + Inter
- Vite (bundler para produccion)

## Arquitectura Modular
- src/styles/components/ - Un CSS por seccion
- src/styles/utilities/ - Animaciones globales + responsive
- src/js/modules/ - Un JS por funcionalidad interactiva
- src/js/utils/ - Helpers reutilizables
